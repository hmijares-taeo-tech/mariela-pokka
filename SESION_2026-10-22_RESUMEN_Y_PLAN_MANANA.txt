           root@<IP_VPS>:/opt/mariela-pokka/

FASE 3: CONFIGURACIÓN DE DOMINIO Y DNS EN NAMECHEAP
  [ ] 6. En el panel de Namecheap para marielapokka.com:
         - Crear registro tipo A: @ -> <IP_VPS>
         - Crear registro tipo A: www -> <IP_VPS>
         - Crear registro tipo A: api -> <IP_VPS> (o backend)
         - TTL: 1 min / Automático.

FASE 4: PUESTA EN MARCHA EN PRODUCCIÓN CON DOCKER
  [ ] 7. Restaurar base de datos en PostgreSQL de producción:
         docker compose -f deploy/docker-compose.yml up -d postgres
         cat data/medusa_backup.sql | docker exec -i mariela-postgres-prod psql -U postgres -d medusa_prod
  [ ] 8. Generar certificados SSL con Certbot (Let's Encrypt gratuito):
         certbot certonly --standalone -d marielapokka.com -d www.marielapokka.com -d api.marielapokka.com
  [ ] 9. Levantar todo el stack en producción:
         docker compose -f deploy/docker-compose.yml up -d --build
